# Model: small or local executor

A procedural scaffold. These are the rules that were written for earlier models and removed for the strong ones. They are untested here: keep a line only if a test shows this model does worse without it.

- Read a file before you edit it.
- Before changing code, write three lines: what changes, where, and how you will check it.
- Make one change at a time, and run the check after each.
- Use the dedicated file and search tools in preference to shell commands.
- Do not create a new file unless the brief asks for one.
- When a command fails, read the whole error before doing anything else.
- You hold the worker seat only. Do not reframe the task; report instead.
