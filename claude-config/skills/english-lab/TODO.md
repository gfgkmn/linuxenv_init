# Deferred

Not built yet, with the reason. Personal figures live in `BASELINE.md` in the
state directory; this file stays generic because the repository is public.

## Wordbook entries that are not activation candidates

The dictionary wordbook records what was looked up **while reading** — input-side
data. This system works on the output side. A word that had to be looked up sits
below every word already read many times and still not produced, so importing
the wordbook wholesale buries the queue under material several rungs too early.

Only the intersection is wired in: looked up, **and** read often, **and** never
produced. On a real wordbook that is a few percent of it.

The rest marks the edge of reading comprehension — a different goal with no
mechanism yet. A separate app was considered and rejected: the system works
because it needs no extra place to go, and a fourth surface is how these things
die. This needs an idea, not a build. Revisit once the main loop has produced
real graduations, and only with something that rides on an existing habit —
reading itself, or the dictionary client the words already live in.

## Prove the daily loop closes

Taught → used unprompted → counted automatically. Every piece is built and
tested in isolation, but the chain has not yet run end to end across days. Only
time settles it.
