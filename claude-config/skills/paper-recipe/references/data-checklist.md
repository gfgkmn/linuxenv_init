# 数据与实现细节清单

逐项填. 论文确实没给的写"论文未给", 与论文类型无关的整节标"不适用", 不要留白,
也不要用合理数值补.

大部分条目在附录而不在正文, 要专门去翻.

---

## 数据集

- [ ] 来源语料 / 构造方式
- [ ] 公开地址 URL 与 license
- [ ] **总条数** (不是"大规模")
- [ ] 样本长度, 以及不同数据集之间长度是否可比
- [ ] **划分方案**: 分成几份, 每份多少条, 图表报的是均值还是单次
- [ ] **每个实验条件至少一条原始例句或样本**, 原文照抄
- [ ] **构造时控制了哪些变量, 哪些没控制住**

最后一条最容易漏, 也最关键. 没控制住的变量可能独立于研究对象主导结果, 而作者有时会
因此主动放弃某组结论. 不记下来, 笔记就会把作者自己都不认的结果写成发现.

## 训练类论文附加 (RL / 后训练 / 微调)

上一节的字段是语料 / 静态数据实验的口径, 训练类论文再补:

- [ ] base model 是哪个, 精确到版本
- [ ] 训练数据配比: 各来源占多少, 有没有给混合比例
- [ ] seed 数量; 图表是单次运行还是多 seed 均值, 方差多大
- [ ] 训练曲线稳定性: 有没有崩过, 报的是最优 checkpoint 还是最终 checkpoint
- [ ] 评测与训练数据的污染检查做没做

## 模型

- [ ] 全名与版本, 不要只写系列名
- [ ] 参数量
- [ ] 哪些在正文展示, 哪些只在附录
- [ ] 权重来源与 license
- [ ] 层数或其他读图时要用到的结构参数

## 算力

- [ ] 什么卡, 几张
- [ ] 每个阶段各花多久
- [ ] 哪一步最贵

复现的人第一个想知道的就是这个. 它直接决定别人做不做得起.

## 指标

- [ ] 每个指标的**精确定义**, 写成公式或伪代码
- [ ] 取值范围, 越大越好还是越小越好
- [ ] **作者对这个指标的保留意见**

最后一条决定了指标能推出什么结论. 漏掉它, 一个只衡量"变化剧烈程度"的指标很容易被
读成"效果变差了".

## 结果的精确计数

- [ ] 每条结论覆盖几个模型或几个数据集, 写成 **x/y 的具体计数**, 不要写"多个""大部分"
- [ ] 例外是哪几个, 例外表现成什么样
- [ ] 效应大小, 方向之外还要有量级

"大部分模型出现该效应"和"n 个里有 m 个出现, 剩下的一个位置偏移、一个方向相反"是两种
完全不同的信息量. 后者才让人判断得了结论有多稳.

## 代码

- [ ] 官方仓库地址
- [ ] 依赖的第三方库及版本
- [ ] **有没有说明用的是默认参数**

最后一条看起来琐碎, 但如果论文依赖的估计器或算法对超参敏感, 一句"全部使用默认参数"
就足以动摇核心结论. 值得专门去找.

## 作者自己声明的限制

- [ ] Limitations 章节逐条抄下来
- [ ] 正文里的保留性表述

作者自己承认的限制分量比读者提出的批评重. 写笔记时要和读者的批评分开标注.
