# 数据与实现细节清单

请逐项填写. 论文未予说明的注明"论文未给", 与论文类型无关的整节标注"不适用". 严禁留白, 亦不得自行填补推测数值.

多数条目位于附录而非正文, 需专门查阅.

---

## 数据集

- [ ] 语料来源 / 构建方式
- [ ] 公开地址 URL 与 license
- [ ] **总条数** (避免使用"大规模"等模糊表述)
- [ ] 样本长度, 以及不同数据集之间的样本长度是否具有可比性
- [ ] **划分方案**: 划分份数, 每份样本量, 图表汇报系单次运行值还是多次均值
- [ ] **每个实验条件至少保留一条原始例句或样本**, 原文照录
- [ ] **构建时控制了哪些变量, 哪些变量未受控制**

末项最易遗漏, 亦最为关键. 未受控变量可能脱离研究对象而主导实验结果, 作者有时亦会因此主动放弃某组结论. 若不予记录, 笔记便会将作者本人已否决的结论误判为有效发现.

## 训练类论文附加 (RL / 后训练 / 微调)

前述字段适用于语料及静态数据实验, 涉及模型训练的论文需补充以下项目:

- [ ] 基座模型 (base model) 具体名称, 精确至版本号
- [ ] 训练数据配比: 各数据源占比, 是否给出了具体的混合比例
- [ ] 随机种子 (seed) 数量; 图表呈现系单次运行还是多 seed 均值, 方差幅度多大
- [ ] 训练曲线稳定性: 过程中是否发生崩溃, 汇报的是最优 checkpoint 还是最终 checkpoint
- [ ] 评测集与训练集之间是否进行了数据污染检验

## 模型

- [ ] 完整名称与具体版本, 勿仅标注系列名称
- [ ] 参数量
- [ ] 哪些模型于正文展示, 哪些仅列于附录
- [ ] 权重来源与 license
- [ ] 网络层数或其他解析图表所需的结构参数

## 算力

- [ ] 计算硬件型号与设备数量
- [ ] 各阶段实验耗时
- [ ] 计算开销最高的步骤

复现研究通常首要关注该项信息, 它直接决定了复现工作的可行性与算力门槛.

## 指标

- [ ] 每个指标的**精确定义**, 整理为公式或伪代码
- [ ] 取值范围, 以及数值大小与性能优劣的对应关系
- [ ] **作者对该指标的保留意见**

末项直接决定了依据该指标所能推导出的结论边界. 若遗漏此项, 一个仅用于衡量"变化剧烈程度"的指标极易被误读为"性能劣化".

## 结果的精确计数

- [ ] 每条结论覆盖的模型或数据集数量, 需记录为 **x/y 的具体计数**, 切勿表述为"多个"或"大部分"
- [ ] 异常或例外情况的具体对象, 以及例外的反常表现形式
- [ ] 效应大小, 除效应方向外需明确具体量级

"多数模型出现该效应"与"n 个模型中有 m 个出现, 其余模型中一个出现位置偏移, 另一个方向相反"所承载的信息量截然不同. 唯有后者方能支撑对结论稳健性的客观评估.

## 代码

- [ ] 官方代码仓库地址
- [ ] 所依赖的第三方库及其版本
- [ ] **是否说明使用了默认参数**

末项看似细微, 但若论文所依赖的估计器或算法对超参数高度敏感, 单凭一句"全部使用默认参数"便足以动摇其核心结论. 该信息值得专门查证.

## 作者自己声明的限制

- [ ] 逐条摘录 Limitations 章节的内容
- [ ] 提取正文中作者阐述的保留性表述

作者自身承认的研究局限性, 其论证权重远高于读者提出的批评意见. 撰写笔记时需将其与读者的批评分开标注.
